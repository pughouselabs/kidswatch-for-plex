# Security

To report a vulnerability, open a private security advisory on GitHub in this
project's repository. Do not put security reports in public issues. If private
advisories are not available, ask the maintainers to enable private reporting
without disclosing vulnerability details.

Include the affected version, steps to reproduce, expected and actual behavior,
and the likely impact. Remove tokens, webhook URLs, account details, child names,
and private server addresses from all examples and logs.

Run behind HTTPS, keep the admin sign-in code enabled, and protect the database
and read-only credential mounts. See README.md for deployment and recovery.
