Companion controls, not a safety lock

In our Jellyfin 12.3 lab, known direct video links still fetched blocked titles, even after playback was turned off. There is no guaranteed cutoff for any client. Native policies and stop requests do not guarantee title security. Strict enforcement is false.

Device results: the Android TV lab client cooperated; the Android phone app kept playing. Physical devices, iOS/tvOS and Roku are untested. Jellyfin Web 12.3.0, in an isolated foreground H.264 direct-play test in Chromium 154, showed a message and Stop closed the player. That one cooperative path does not close the server bypass. Android TV source supports stop and messages, but both player engines and physical devices need runtime tests. Swiftfin source supports stop; do not promise a friendly message without testing the installed version. Treat Roku remote stop and messages as unsupported for this preview. No client is certified for strict enforcement.

What can parents manage?

KidsWatch for Jellyfin is a self-hosted preview for family library choices and time routines. Native controls are a best-effort companion, with no strict title security or guaranteed cutoff.

  • Titles by age. Parents pick Little kids, Kids or Teens and whole-series title choices. Selection excludes R, NC-17, TV-MA, unknown and unrated titles; filtering is not secure playback blocking.
  • Screen time and watch hours. Daily minutes and watch hours for school days and weekends, with presets for the school year and summer.
  • Pause and extra time. Parents can pause watching, add time for today, or push bedtime back. Extra time and later bedtimes reset the next day.
  • Activity. A 7-day chart of reported usage, parent changes and recorded stop requests. Unconfirmed playback outcomes must stay unconfirmed.
  • You stay in charge. Only invited eligible local adults can request parent access. Parent approval and child activation are separate checks. The owner controls trusted parents and answers requests.

Before you install

What you need

  • Your own Jellyfin Media Server with movie or TV libraries you are allowed to share.
  • A dedicated owner-created admin integration key. Store it in Vaultwarden and mount it as a protected runtime secret. It is privileged server access and stays on the backend; parents never need it.
  • Docker with Docker Compose v2, on a machine that can reach your Jellyfin server.
  • A web address with HTTPS so parents can reach the site, for example through a reverse proxy like Caddy.
  • A private way to receive owner notifications. Verify owner notifications before inviting parents. Keep privileged server access on the backend, and review the planned setup with the server owner.
  • A restricted local Jellyfin user for each child, created by KidsWatch and verified before device setup. No outside account or email address is needed.

Match the household timezone on both services, choose the child approval policy and verify owner notifications before inviting parents.

Privacy and security

Your hardware. Your families' data.

  • No KidsWatch cloud

    No outside child signup or cloud account. Parents use existing local Jellyfin identities. The privileged integration key stays on the backend.

  • Protected server integration

    The owner configures protected HTTPS access and selected libraries. Keep the dedicated integration key in protected runtime storage and out of parent devices, chat and logs.

  • Private family data

    Keep local child identities, rules, usage, requests, integration secrets and any matching backups private. The preview does not connect this website to your server.

  • Owner-controlled access

    Owner invitations, parent approval and child activation are separate checks. An invitation alone grants no access. Protect HTTPS access and verify owner notifications before inviting parents.

It can create local Jellyfin users and change native policies. Treat it like privileged server access: use HTTPS, private backups and protected runtime secrets.

Limitations to know before you start

KidsWatch does a few things well. It is honest to say what it does not do.

  • It is not a device lock. Known direct video links fetched blocked titles in our Jellyfin 12.3 lab, even after playback was turned off. Playback setup and direct streaming still worked. Buffered video may continue. No strict title security or guaranteed cutoff for any client.
  • Rules follow the child's own account. If a child uses an adult account, child rules do not apply. Keep adult and admin identities unavailable for easy switching on shared TVs.
  • It only covers your server. It does not filter anything played from other servers or other apps.
  • New titles take a little while. Library selections and native policy readback do not prove secure playback blocking. Test the actual child experience and record results for the exact version.
  • Ratings come from your library. A title with a wrong rating still needs a parent to look at it.
  • Jellyfin can change. Jellyfin server and client behavior can change. Readiness stays at companion controls only; a connected server, saved policies or a successful health check do not prove title security or a cutoff.
  • One copy per database. Run a single container. It is not built to scale out.
Common questions
Does it cost anything?

The Jellyfin edition is a preview, with no public build or download available yet. No outside child account or Plex subscription is needed.

Does a parent need the admin integration key?

No. Parents use their existing local Jellyfin identity and need owner-approved family access. The privileged integration key stays on the backend.

Does each child need an email address?

No. KidsWatch creates a restricted local Jellyfin user for each child. There is no external child signup or Plex share to accept. Sign in the TV with Quick Connect or parent-assisted child login.

Does it send any data to you?

No. There is no telemetry and no outside service run by us. Everything is stored on your machine.

Can kids get around it?

Yes. Known direct video links fetched blocked titles even with playback disabled in the Jellyfin 12.3 lab. Downloads, disconnected players, casting and saved adult accounts can bypass the intended experience. Shared TVs should not leave adult or admin accounts available for easy switching.

What happens if KidsWatch is down?

Usage depends on player reports. If the server is offline, contact is lost or sessions are stale, the owner needs to check it. Time accounting can be incomplete, and stop requests do not guarantee playback ended.

How do I remove it?

Read the planned guidance in Removing. For a future reviewed Jellyfin release, use its matching instructions and backups, review only the local child users it created and verify sign-in after a restore.
